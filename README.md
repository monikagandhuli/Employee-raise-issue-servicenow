Employee Raise Issue – Record Producer & Service Portal

Project Overview

This project aims to help employees report workplace issues through a ServiceNow application.

Problem Statement

Employees often report payroll discrepancies, access problems, infrastructure requests, and HR policy questions through emails or informal channels. This can cause delays, inconsistent tracking, and poor visibility into issue status.

Objectives

Provide a standard form for raising employee issues.

Store issue details in a custom table.

Use a Record Producer for issue submission.

Provide access through a Service Portal.

Track issue status and resolution.
